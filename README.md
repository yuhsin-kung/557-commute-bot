# 557 通勤平台：東吳通勤達人 LINE Bot

東吳大學外雙溪校區的通勤小幫手。557 是從士林站到外雙溪校區最常用、也最擠的公車，這個 LINE Bot 幫學生查即時到站、比較其他路線、提醒下雨和考試週，並把每一筆使用紀錄存下來，整理成給學校的數據。

- **LINE 官方帳號**：東吳通勤達人 `@311zktcn`
- **黑客松初賽截止**：2026/10/30（四）中午 12:00，應用性占 40%，**要有真人測試數據**
- **技術**：LINE Messaging API + Google Apps Script + Google Sheets，不用架伺服器

### 比較器的核心發現

從**捷運士林站(中正)** 上車，有 13 條公車跟 557 **走一模一樣的 6 站**到「東吳大學(錢穆故居)」站：

> 255、255區、304承德、304重慶、680、683、683預、957、北環幹線、紅30、小18、小19、市民小巴1

557、300 會再多開一站進校園（「東吳大學」站），通勤30 是直達。所以在士林站**不用死等 557**，哪班先來搭哪班，到錢穆故居站下車走進學校就好。

文湖線：**捷運劍南路站** 有 268、681、683、957、北環幹線；**捷運大直站** 有 680。

### 2. 金鑰放在哪裡

金鑰**只放兩個地方**：

1. **本機的 `keys.env`**（不會上傳 GitHub）
2. **Apps Script → ⚙️ 專案設定 → 指令碼屬性**（Bot 實際用的是這裡）

> 💡 **接手的人不一定要拿 `keys.env`**：試算表共用給你（編輯者）之後，打開 Apps Script → ⚙️ 專案設定 → 拉到最下面「指令碼屬性」，就能看到全部金鑰。只改 Apps Script 程式的話，直接用那裡的就好。
>
> ⚠️ 反過來說，**任何有試算表「編輯者」權限的人都看得到所有金鑰**。所以：
> - 試算表只共用給隊員，**不要開「知道連結的任何人都能編輯」**
> - 給計數的同學、測試的同學用的是**表單填寫網址**和 **LINE Bot**，不要給他們試算表的編輯權限
> - 只需要看數據的人（例如德育中心、評審），共用時選「**檢視者**」，或另外匯出一份給他們
> - 有隊員退出，就把他移出共用，並[重新產生金鑰](#-金鑰)

指令碼屬性要有這 5 個（名稱要一模一樣）：

```
TDX_CLIENT_ID
TDX_CLIENT_SECRET
CWA_API_KEY
LINE_CHANNEL_ACCESS_TOKEN
GEMINI_API_KEY
```

> 沒有 `GEMINI_API_KEY` 也能跑，比較器會改用規則判斷（抓時間、大樓代號），只是比較聽不懂口語。

### 3. 打開 Apps Script

1. 用隊伍 Gmail 打開「**557 通勤平台**」試算表
2. **擴充功能 → Apps Script**
3. 會看到 `程式碼.gs`（＝`Code.gs`）、`比較器.gs`，之後可能還有 `計數表單.gs`

如果打不開、出現「很抱歉，目前無法開啟這個檔案」，看[注意事項](#google-多帳號登入)。

### 4. 試算表的分頁

| 分頁 | 誰寫的 | 內容 |

| 訊息紀錄 | Bot 自動 | 每一則訊息：時間、使用者 ID、問題、回覆 |
| 比較器紀錄 | Bot 自動 | 每次比較：出發站、大樓、上課時間、模式 |
| 訂閱 | Bot 自動 | 誰訂閱了晚上提醒 |
| 推播紀錄 | 每晚自動 | 每晚檢查結果：明早降雨機率、是否考試週、發給幾人、剩餘額度 |

## 修改程式後怎麼更新

1. 改本機 `bot/` 裡的檔案（或請 Claude 改）
2. 到 Apps Script 打開對應的檔案，**`Ctrl+A` 全選 → 刪光 → 貼上新的**
3. `Ctrl+S` 存檔，確認上面的「尚未儲存變更」消失
4. 上方下拉選單選測試函式（`測試` 或 `測試比較器`）→ ▶ 執行，看執行記錄有沒有錯
5. **部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**
6. 用手機傳訊息給 Bot 確認
7. commit 到 GitHub

> ⚠️ 第 5 步一定要做，不然 LINE 用的還是舊版程式。
> ⚠️ 不要按「**新增部署作業**」，那會產生新網址，LINE 的 Webhook 就要重設。

## 測試方法

### 在 Apps Script 裡測（不用手機）

| 函式 | 做什麼 |
|---|---|
| `測試` | 印出 557 去學校、557 回家、降雨機率，並寫一筆到「訊息紀錄」 |
| `測試比較器` | 用 4 句範例問比較器 |
| `建立計數表單` | **只執行一次**，建立士林站計數表單，網址印在執行記錄 |
| `設定晚上提醒排程` | **只執行一次**，設定每晚 9 點自動執行「晚上提醒」（重複執行不會重複設定） |
| `測試晚上提醒` | 只印出來、不發送：未來 3 天和 11/9 期中考各會不會提醒、訂閱人數、剩餘額度 |
| `試發給訂閱者` | ⚠️ 強制發測試訊息給所有訂閱者，**會用掉額度** |
| `設定站位檢查排程` | **只執行一次**，設定每 6 小時檢查德育中心頁面，並記下現在的頁面當比對基準 |
| `測試站位變更` | 不推播：假裝站牌搬家、只改排版，看 Gemini 的摘要和判斷 |
| `設定共乘排程` | **只執行一次**，設定每分鐘檢查共乘（成團、沒出現、出發提醒），並建立三個共乘分頁 |

> 不要直接執行 `doPost`，它是等 LINE 傳訊息進來才用的，直接執行一定會出現 `Cannot read properties of undefined (reading 'postData')`。

## ⚠️ 注意事項（一定要看）

### 🔑 金鑰

- **`keys.env` 絕對不能上傳 GitHub、不能傳到群組**。`.gitignore` 已經擋住了，但 `git add` 前還是看一下 `git status`
- **不要把金鑰貼在聊天裡、不要截圖**。截圖前先把金鑰遮住
- 金鑰外流了就到該平台**重新產生**（LINE 的 Channel secret 旁邊有 Issue 按鈕、Gemini 刪掉重建），再更新 `keys.env` 和指令碼屬性
- 之前有一把 Gemini 金鑰所在的 Google Cloud 專案被停權，**現在用的是建在新專案的金鑰**。如果又被停權，換一個用比較久、已滿 18 歲的個人帳號申請

### 💬 LINE

- **免費方案每月只能主動推播 200 則**（以人次計算：50 人收一次提醒＝50 則）。「回覆」不限次數、不收費。所以：
  - 功能盡量設計成學生先問、Bot 回覆
  - 推播只發給有訂閱的人，雨天和考試週合併成一則（`晚上提醒.gs` 已經這樣做）
  - 明天是週末、放假不發；**額度不夠時不發**，會記在「推播紀錄」
  - 剩餘額度：`GET https://api.line.me/v2/bot/message/quota/consumption`
- 官方帳號的「**自動回應訊息**」要關掉、「**Webhook**」要開，不然會跟 Bot 搶著回
- LINE Developers 的 Webhook「Verify」按鈕對 Apps Script 有時會顯示錯誤，**不用理它**，用手機實際傳訊息測就好
- Apps Script 讀不到 HTTP header，所以**沒辦法驗證 LINE 的簽章**（`X-Line-Signature`）。原型可以接受，正式上線前要改成有伺服器的架構

### 🚌 TDX

- TDX 有**每秒呼叫次數限制**，太快會回 `429 API rate limit exceeded`。比較器一次只查一個站牌的所有路線，並快取 30 秒；token 快取 6 小時
- 用 Python 3.14 以上連 TDX 會出現 `CERTIFICATE_VERIFY_FAILED: Missing Subject Key Identifier`，要把 SSL 的 `VERIFY_X509_STRICT` 關掉（一樣有驗證憑證，只是不那麼嚴格）。Apps Script 沒有這個問題
- **TDX 沒有 557 的站間行駛時間資料**（`S2STravelTime` 回傳空的），所以車程是估計值，要自己記錄校正

### 🛠 Apps Script 常見問題

<a id="google-多帳號登入"></a>
- **打不開 Apps Script**（「很抱歉，目前無法開啟這個檔案」，網址有 `authuser=2`）：瀏覽器同時登入多個 Google 帳號造成的。用**無痕視窗**只登入隊伍帳號，或開一個專用的 Chrome 設定檔
- **「這個應用程式未經 Google 驗證」**：自己寫的程式都會出現。確認開發人員是隊伍帳號 → 進階 → 前往（不安全）→ 允許
- **「尚未儲存變更」存不了**：某個檔案有語法錯誤。按 `Ctrl+S` 看紅色錯誤訊息的「行數」和「檔案」。最常見是**複製時漏了第一行 `/**`**，或新程式貼在舊程式下面變成兩份
- **執行到 `myFunction`**：上方下拉選單要選對函式
- **Gemini 免費版有每分鐘次數限制**：`gemini-3.5-flash` 每分鐘只有 **5 次**，超過會回 `429`。所以比較器**先用規則**，規則看不懂才叫 Gemini（先 `gemini-3.5-flash-lite`，失敗再換 `gemini-3.5-flash`），都失敗還是用規則回答。測試時不要在一分鐘內連續跑太多次
- 比較舊的 `gemini-flash-latest` 常常塞車（20～50 秒或 503），不要用

- 現場計數**只數人數、不拍照、不記錄任何人的長相或是誰插隊**

### 📮 悠遊卡刷卡數據（暫緩）

- TDX「票證服務」只能**瀏覽資料目錄**，真正的資料要到**交通部數據匯流平臺**申請：申請單＋證明文件＋**用印**，寄到指定信箱
- 要申請的資料：**臺北市公車電子票證資料（TO1 或 TO1A）**、公車每日各站分時 OD (O)、(D)、公車分時旅運量

- 待確認（打電話問 (02) 2349-2818 / tdc@motc.gov.tw）：學生能不能用個人名義申請、要不要學校或指導老師用印、審核多久、TO1 和 TO1A 差在哪
