# 557 通勤平台：東吳通勤達人 LINE Bot

東吳黑客松・流程改善組。幫外雙溪校區學生分散 557 尖峰人潮的 LINE Bot（`@311zktcn`）。

- **技術**：LINE Messaging API + Google Apps Script + Google 試算表，全部免費額度
- **程式**：`bot/` 是備份，**真正在跑的在 Apps Script**，改程式兩邊都要改
- **細節**：指令、規則、試算表欄位看 [LINE指令說明.md](LINE指令說明.md)

## 功能

| 選單 | 功能 |
|---|---|
| 出門前提醒 | 比較所有路線（公車＋YouBike＋計程車共乘）、出門時間建議、557 發車前提醒、557 即時動態、降雨查詢、雨天與考試週訂閱提醒 |
| 557 以外的選擇 | 計程車共乘、YouBike 車數、共享雨傘（規劃與 Raingo 合作）、包車調查（規劃中） |
| 公車站牌與排隊禮儀 | 557 最新上車地點、排隊禮儀短片；站牌改了推播給所有好友 |
| 積分與打卡 | 定位打卡（早到、步行）、騎車到校（截圖驗證）、集滿 5 點換 30 元學餐折價券、我的紀錄、全校減碳 |
| 學校端 | 每晚 10 點 AI 整理每日報表，寄給德育中心、軍訓室 |

加好友時會自動推送新生須知。

## 設定

**1. 指令碼屬性**（Apps Script → 專案設定）

- 必填：`LINE_CHANNEL_ACCESS_TOKEN`、`TDX_CLIENT_ID`、`TDX_CLIENT_SECRET`、`CWA_API_KEY`、`GEMINI_API_KEY`
- 選填：`REPORT_EMAILS`（報表收件人）、`ETIQUETTE_VIDEO_URL`、`NEWBIE_VIDEO_URL`、`RAINGO_URL`、`CHARTER_FORM_URL`（包車表單）

**2. 在編輯器各執行一次**：`設定晚上提醒排程`、`設定站位檢查排程`、`設定共乘排程`、`設定每日報表排程`、`設定557紀錄排程`

**3. 試算表**：手動匯入 `bot/行事曆.csv`，分頁名稱叫「行事曆」；其他分頁 Bot 會自己建。

**4. LINE 後台**：自動回應關閉、Webhook 開啟。圖文選單用 `design/圖文選單.png`（大型 4 格），四格傳出的文字：`出門前提醒`、`557 以外的選擇`、`公車站牌與排隊禮儀`、`積分與打卡`。

## 改程式

1. 改 `bot/` 裡的檔案，跑 `npm test`
2. 貼到 Apps Script 對應的檔案，存檔
3. **部署 → 管理部署作業 → ✏️ → 新版本**（不要按「新增部署作業」，網址會變）
4. 手機測試，commit

`npm run validate:line` 會檢查卡片格式 LINE 收不收（需要 `keys.env`）。

## 557 監測（電腦上跑）

`tools/557監測.py` 每 15 秒從臺北市公車動態網站記錄 557，整理成 Excel（`data/557監測/`）：每班車的天文館發車時間、到士林國中之前每一站的時間和每段幾分鐘、到士林國中、捷運士林站、東吳的時間，以及離開士林國中、捷運士林站時的車上人數（綠舒適、黃中等、紅擁擠）。

雙擊 `tools/開始監測557.bat`，或：

```powershell
uv run tools/557監測.py
```

預設等到 07:00 開始、19:00 結束；`--now --minutes 10` 立刻測試 10 分鐘；`--rebuild 2026-11-25` 用原始紀錄重新產生 Excel。測試：`uv run --with openpyxl python -m unittest discover -s tests -p "test_*.py"`。

人數是車「離開」那一站後網站回報的車上人數，所以士林站只看得到「上車 − 下車」的淨值；人數怎麼算的網站沒公開，要用現場觀察核對。

## 注意

- **金鑰**：只放在 `keys.env`（不上傳）和指令碼屬性。試算表編輯者看得到所有金鑰，不要亂共用
- **LINE 推播**：免費每月 200 則。站位變更會發給所有好友，好友多時很耗額度
- **557 到站紀錄**：`到站紀錄.gs` 每分鐘（06:00–20:30）從臺北市公車動態網站（pda5284.gov.taipei）記錄 557 每台車的到離站、擁擠程度、車上人數，以及網站預估的到站秒數，存在「557動態紀錄」「557預估紀錄」分頁，給到校時間預測用。不用金鑰、不耗 TDX 點數
- **TDX**：有每秒次數限制，不要大量下載歷史資料（曾因此被停權）
- **估計值**：車程、步行時間、碳排係數還沒實測，數字在 `比較器.gs`、`積分.gs`
